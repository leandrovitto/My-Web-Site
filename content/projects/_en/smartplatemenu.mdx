**Live multi-tenant SaaS for the restaurant industry**, designed and built from scratch.

Covers the full operational flow: public digital menu, admin panel, and multi-channel order management (dine-in, take-away, delivery). The architecture is designed to onboard new tenants without manual intervention.

<b>Production-Grade Stack:</b>

- **Monorepo**: Turborepo
- **Frontend / Backend**: Next.js App Router, Fastify
- **Database**: Drizzle ORM, Neon/Postgres
- **Auth & Payments**: Better Auth, Stripe
- **AI**: Agent + Claude API for automatic menu generation
- **Deploy**: Docker Swarm + Vercel, branch-based stg/prod environments
