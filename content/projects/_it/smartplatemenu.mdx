**SaaS multi-tenant live per la ristorazione**, progettato e sviluppato da zero.

Copre l'intero flusso operativo: menu digitale pubblico, admin panel e gestione ordini multi-canale (dine-in, take-away, delivery). L'architettura è pensata per onboardare nuovi tenant senza intervento manuale.

<b>Stack Production-Grade:</b>

- **Monorepo**: Turborepo
- **Frontend / Backend**: Next.js App Router, Fastify
- **Database**: Drizzle ORM, Neon/Postgres
- **Auth & Payments**: Better Auth, Stripe
- **AI**: Agente + Claude API per generazione automatica del menu
- **Deploy**: Docker Swarm + Vercel, ambienti branch-based stg/prod
